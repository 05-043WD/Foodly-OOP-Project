# 🍔 Foodly - Online Food Delivery Management System

## 📖 Project Overview
This is a web-based application developed for the **SE1020 Object-Oriented Programming** module at SLIIT. The system allows users to manage and interact with a food delivery network, applying core OOP concepts (Encapsulation, Inheritance, Polymorphism, Abstraction) and utilizing file handling for persistent data storage.

## 👥 Team Members & Module Distribution
The project is divided into 6 core modules. Each member is responsible for the Model, Service, and Controller logic within their respective domain.

| Member | Module | Primary Responsibility | Key Files to Study |
| :--- | :--- | :--- | :--- |
| **Sayumi** | **User Accounts** | Login & Registration logic | `User.java`, `UserService`, `UserController` |
| **Amaan** | **Food Menu** | Adding/Editing dishes & prices | `FoodItem.java`, `FoodItemService`, `MenuController` |
| **Menuja** | **Orders & Cart** | Shopping Cart, Checkout, Address | `Order.java`, `OrderService`, `CartController` |
| **Chameesha** | **Staff Admin** | Managing employees/staff list | `Staff.java`, `StaffService`, `StaffController` |
| **Irusha** | **Promos** | Creating/Validating discount codes | `Promo.java`, `PromoService`, `PromoController` |
| **Lithika** | **Reviews** | Customer feedback & moderation | `Review.java`, `ReviewService`, `ReviewController` |

## 🛠️ Tech Stack
*   **Backend:** Java (Spring Boot Framework)
*   **Frontend:** HTML5, CSS3, Thymeleaf Templates
*   **Data Storage:** File I/O operations (CRUD via `.txt` files)
*   **Build Tool:** Maven
*   **IDE:** IntelliJ IDEA
